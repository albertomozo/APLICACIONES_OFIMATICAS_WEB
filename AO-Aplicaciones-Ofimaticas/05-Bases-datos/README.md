## 💾 UD 5: Utilización de bases de datos ofimáticas (50 h)

Aquí es crucial modernizar, pasando de Access (opcional) a **bases de datos más sencillas, versátiles y colaborativas** que actúan como "hojas de cálculo avanzadas".

| Contenido Moderno | Enfoque y Justificación |
| :--- | :--- |
| **1. Fundamentos de Bases de Datos Relacionales (Teoría Light)** | **Conceptos clave**: **Tabla**, **Registro**, **Campo**, **Clave Primaria**. Diferencia con una hoja de cálculo plana. |
| **2. Bases de Datos Colaborativas y "Low-Code"** | **Airtable** o **Notion (Bases de datos)**. Creación de tablas, tipos de campos (fórmula, lookup, linked record). Esto es un *skill* muy demandado en gestión de proyectos.  |
| **3. Diseño de Consultas y Vistas Avanzadas** | Uso de **Filtros** y **Agrupaciones**. Creación de diferentes **Vistas** de los mismos datos (Vista de Galería, Kanban, Calendario). |
| **4. Introducción a Microsoft Access (Opcional o Reducido)** | Si se mantiene, centrarse solo en la **Creación de tablas** y **Relaciones básicas** y la **Creación de Consultas simples**. |
| **5. Conexión de Datos (Importación y Exportación)** | Importar datos desde **Excel** o **CSV**. Exportar para su uso en otras herramientas (ejemplo: usar los datos para una combinación de correspondencia avanzada en UD2). |
