# 📄 02 - Procesador de Texto

Módulo completo de formación en procesadores de texto (Word, Google Docs, LibreOffice Writer). Incluye guías teóricas, ejercicios prácticos y recursos de apoyo para dominar la redacción, formato y maquetación de documentos.

## 🎯 Descripción General

Este módulo cubre desde los fundamentos hasta técnicas avanzadas en procesadores de texto:

- ✅ Análisis de paquetes ofimáticos
- ✅ Formateo básico y estilos
- ✅ Estilos avanzados y plantillas
- ✅ Diseño y maquetación
- ✅ Trabajo con imágenes
- ✅ Tablas, gráficos y listas
- ✅ Formularios
- ✅ Revisión y comentarios
- ✅ Impresión y exportación
- ✅ Colaboración y compartición
- ✅ Comparativa entre plataformas

## 💡 Consejos de Uso

1. **Comienza con el análisis**: Lee `E_00_analisis_paquetes_ofimaticos.md` para entender las diferencias entre plataformas
2. **Sigue la secuencia**: Los ejercicios están ordenados de menor a mayor complejidad
3. **Consulta las guías**: Cada ejercicio tiene una guía teórica asociada
4. **Practica regularmente**: Los ejercicios incluyen tareas prácticas aplicables
5. **Proyecto final**: Realiza el proyecto integrador después de dominar los conceptos individuales

---

## 📝 Notas Importantes

- Las guías incluyen información comparativa entre Word, Google Docs y LibreOffice Writer
- Los ejercicios pueden adaptarse a diferentes plataformas según sea necesario
- Hay varias versiones de algunos ejercicios (enunciado, con asignaciones, etc.)
- Las carpetas dentro de ejercicios (E_08_triptico, E_10_compartir_enunciado) contienen recursos complementarios
- Se recomienda revisar `00-indice.md` para tener una visión general antes de comenzar
