## 📚 Contenidos Temáticos

### 1. Edición de Vídeo Online y Móvil

**Herramientas principales:**
- **CapCut** (PC/Móvil) - Editor profesional gratuito
- **DaVinci Resolve** (versión gratuita) - Edición avanzada
- **Editores móviles** - Edición en smartphones

**Conceptos clave:**
- Cortes y transiciones
- Música sin copyright
- Sincronización de audio y vídeo
- Efectos y filtros

---

### 2. Contenido Corto (Reels, TikTok, Shorts)

**Características:**
- Formato vertical (9:16)
- Duración corta (15-60 segundos)
- Subtítulos automáticos
- Enganches visuales

**Plataformas:**
- Instagram Reels
- TikTok
- YouTube Shorts
- Facebook Stories

---

### 3. Grabación y Producción Básica

**Herramienta:** OBS Studio (gratuito y multiplataforma)

**Funciones:**
- Grabación de pantalla
- Captura de cámara
- Grabación simultánea (pantalla + cámara)
- Streaming en directo
- Ideal para tutoriales y cursos

---

### 4. Publicación y Distribución

**Optimización para YouTube:**
- Títulos atractivos
- Etiquetas relevantes
- Miniaturas profesionales
- Descripciones SEO

**Redes Sociales:**
- Formato adaptado a cada plataforma
- Duración optimizada
- Subtítulos quemados (hardcoded)
- Llamadas a la acción

### 📝 Guía 2: Subtítulos - Creación y Gestión

**Ubicación:** `guias/subtitulos.md`

**Contenido:**

#### Métodos de Generación

**Para vídeos con audio:**
- CapCut (opción más rápida)
- YouTube Studio (profesional gratuito)
- Riverside.fm (alta precisión)

**Para vídeos sin audio:**
- Anotación manual (CapCut)
- Aegisub (precisión en milisegundos)
- Truco de "Narración Espejo"

#### Tipos de Subtítulos

| Aspecto | Incrustados | Opcionales |
|--------|-----------|-----------|
| **Almacenamiento** | Quemados en vídeo | Archivo aparte |
| **Editable** | ❌ No | ✅ Sí |
| **Desactivable** | ❌ No | ✅ Sí |
| **Ideal para** | Redes sociales | YouTube, VLC |

#### Formatos de Archivo

- **`.SRT` (SubRip):** Universal, texto plano
- **`.ASS` (Advanced Substation Alpha):** Personalización avanzada

#### Sincronización Técnica

- Regla del nombre identificador
- Uso de VLC
- Contenedores (MKVToolNix)

#### Ideas Creativas

- Subtítulos como metadatos
- Guías visuales en tutoriales
- Código de colores por categoría
- Traducción eficiente

## 🔄 Flujo de Trabajo Típico

### Paso 1: Pre-producción
```
Planificación → Guión → Preparación de recursos
```

### Paso 2: Captura/Grabación
```
OBS Studio (pantalla) → Cámara/Micrófono → Archivo bruto
```

### Paso 3: Edición
```
Importar en CapCut → Cortes y transiciones → Texto y efectos
```

### Paso 4: Audio y Subtítulos
```
Sincronizar audio → Subtítulos automáticos (CapCut o YouTube)
```

### Paso 5: Transcripción (opcional)
```
Exportar audio → Riverside.fm o Otter.ai → Obtener texto
```

### Paso 6: Optimización
```
Ajustar colores → Compresión → Adaptar formato (16:9 o 9:16)
```

### Paso 7: Publicación
```
Crear miniatura → Escribir descripción → Cargar a plataforma
```

## 📊 Formatos Recomendados

### Por Plataforma

| Plataforma | Resolución | Ratio | Duración | Formato |
|-----------|-----------|-------|----------|---------|
| **YouTube** | 1920x1080 (Full HD) | 16:9 | Variable | MP4 |
| **Instagram Reels** | 1080x1920 | 9:16 | 15-90s | MP4 |
| **TikTok** | 1080x1920 | 9:16 | 15-60s | MP4 |
| **Facebook** | 1200x627 (portada) | Varía | 60s | MP4 |
| **LinkedIn** | 1200x627 | 16:9 | Variable | MP4 |

### Codificación Recomendada

- **Vídeo:** H.264 (MPEG-4), bitrate 5-8 Mbps
- **Audio:** AAC, 128-192 kbps
- **Contenedor:** MP4

## ✅ Buenas Prácticas

### Edición
✅ Mantén el pacing constante
✅ Usa transiciones de forma moderada
✅ Sincroniza audio con visuales
✅ Deja silencio antes/después del contenido principal

### Subtítulos
✅ Letra clara y legible
✅ Contraste suficiente con el fondo
✅ No cubras elementos importantes del vídeo
✅ Sincronización precisa

### Transcripción
✅ Revisa la precisión antes de usar
✅ Mantén coherencia de términos técnicos
✅ Añade puntuación adecuada
✅ Guarda en formato `.srt` para portabilidad

### Publicación
✅ Optimiza título y descripción para SEO
✅ Crea miniatura personalizada
✅ Añade keywords relevantes
✅ Incluye call-to-action

## 📝 Notas Importantes

- Los subtítulos **automáticos** tienen ~85-95% de precisión; revisa siempre
- Para **máxima calidad**, exporta en 1080p (Full HD) como mínimo
- Los archivos MP4 son el estándar universal
- Usa **música sin copyright** (YouTube Audio Library, Epidemic Sound)
- Los vídeos **verticales** (9:16) funcionan mejor en mobile
- Los subtítulos **quemados** son permanentes; úsalos para redes sociales
