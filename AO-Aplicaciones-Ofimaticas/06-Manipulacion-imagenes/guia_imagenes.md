### 1. Herramientas de Edición Rápida en la Nube

Las herramientas de edición rápida en la nube permiten manipular imágenes sin necesidad de instalar software pesado en el dispositivo local. Se accede a través de navegadores web, facilitando el trabajo colaborativo y el acceso desde cualquier lugar.

- **Canva**: Es una plataforma de diseño gráfico intuitiva y gratuita (con opciones premium). Permite crear y editar imágenes, posters, banners y contenido para redes sociales de manera rápida. Incluye plantillas prediseñadas, elementos gráficos y herramientas de edición básica como recortes, filtros y texto. Justificación: Ideal para usuarios no expertos, ya que su interfaz drag-and-drop acelera la creación de contenido visual profesional sin conocimientos avanzados de diseño.

- **Photopea**: Un editor de imágenes gratuito en línea que replica las funcionalidades de Adobe Photoshop. Soporta archivos PSD y ofrece herramientas avanzadas como capas, máscaras, ajustes de color y efectos. Justificación: Útil para retoques más complejos, como la edición de fotos o la creación de gráficos detallados, sin costo y sin instalación.

### 2. Fundamentos de la Imagen Digital

Entender los fundamentos de la imagen digital es esencial para manipularlas correctamente, ya que afecta la calidad, el tamaño del archivo y su uso final.

- **Resolución (DPI/PPI)**: La resolución mide la densidad de puntos o píxeles por pulgada (DPI para impresión, PPI para pantallas). Una resolución alta (ej. 300 DPI) es necesaria para impresión de alta calidad, mientras que para web basta con 72-96 PPI. Definición: Es la cantidad de detalle en una imagen; mayor resolución significa más nitidez pero archivos más grandes.

- **Píxeles**: Unidad básica de una imagen digital, representada como un punto de color. Una imagen se compone de una cuadrícula de píxeles. Definición: Cada píxel contiene información de color (en modelos como RGB), y el número total determina el tamaño y la calidad de la imagen.

- **Formatos de Imagen**:
  - **JPG (JPEG)**: Formato comprimido ideal para fotos con muchos colores. Pierde calidad al comprimir, pero reduce el tamaño del archivo. Definición: Usa compresión con pérdida para optimizar almacenamiento.
  - **PNG**: Soporta transparencia y compresión sin pérdida. Ideal para gráficos con fondos transparentes o texto. Definición: Mantiene la calidad original, pero archivos más grandes que JPG.
  - **SVG**: Formato vectorial escalable, perfecto para iconos y gráficos que se redimensionan sin perder calidad. Definición: Basado en vectores (líneas y curvas matemáticas), no en píxeles, lo que lo hace ideal para web responsiva.

- **Modelos de Color**:
  - **RGB (Red, Green, Blue)**: Modelo aditivo usado en pantallas digitales (web, monitores). Combina rojo, verde y azul para crear colores. Definición: Cada color se representa con valores de 0-255 por canal.
  - **CMYK (Cyan, Magenta, Yellow, Black)**: Modelo sustractivo para impresión. Usa tintas para absorber luz. Definición: Diferencia clave con RGB: RGB emite luz, CMYK refleja; conversiones entre modelos pueden alterar colores.

### 3. Optimización de Imágenes para Web

La optimización asegura que las imágenes carguen rápido en sitios web, mejorando la experiencia del usuario y el SEO.

- **Redimensionamiento**: Ajustar el tamaño de la imagen a las dimensiones necesarias (ej. 1920x1080 px para banners). Definición: Reduce el número de píxeles para disminuir el peso del archivo sin alterar la proporción.

- **Compresión**: Técnica para reducir el tamaño del archivo aplicando algoritmos que eliminan datos redundantes. Definición: Compresión con pérdida (JPG) elimina detalles imperceptibles; sin pérdida (PNG) mantiene calidad pero reduce menos el tamaño.

- **Herramientas Online**: 
  - **TinyPNG**: Comprime imágenes PNG y JPG sin pérdida significativa de calidad, optimizando para web.
  - **Compressor.io**: Ofrece compresión avanzada con opciones de calidad ajustable. Justificación: Estas herramientas gratuitas automatizan el proceso, ahorrando tiempo y asegurando compatibilidad con estándares web.

### 4. Licencias y Recursos Gratuitos

Usar recursos libres evita problemas legales y fomenta la creatividad ética.

- **Copyright**: Derecho exclusivo del creador sobre su obra, que prohíbe copiar, distribuir o modificar sin permiso. Definición: Protege creaciones originales; infracciones pueden llevar a sanciones legales.

- **Licencias Creative Commons (CC)**: Alternativas al copyright que permiten compartir obras con condiciones específicas (ej. CC BY: atribución obligatoria; CC0: dominio público). Definición: Facilitan el uso libre de contenido cultural, promoviendo la colaboración.

- **Bancos de Imágenes Gratuitos**:
  - **Unsplash**: Biblioteca de fotos de alta calidad libres de derechos, con licencia CC0.
  - **Pexels**: Similar a Unsplash, ofrece imágenes y vídeos gratuitos para uso comercial y personal. Justificación: Proporcionan recursos de calidad sin costo, ideales para proyectos educativos y profesionales, siempre citando la fuente si es requerido.
