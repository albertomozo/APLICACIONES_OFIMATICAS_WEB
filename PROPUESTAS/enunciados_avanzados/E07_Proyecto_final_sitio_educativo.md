# Ejercicio 7 — Proyecto final: Sitio web educativo (integración completa)

**Objetivo:**
En equipo, construir un sitio educativo modular (curso corto) que combine CMS/static site, multimedia, ejercicios interactivos, base de datos de usuarios y panel docente mínimo.

**Entregables:**
- Sitio desplegado (URL o carpeta `final_site/`).
- Repositorio con código, assets y scripts (`repo/`).
- Base de datos con usuarios de prueba y datos de progreso (`db/`).
- Documentación pedagógica y técnica (`README.md`, `deploy.md`).

**Pasos sugeridos:**
1. Planificación curricular (módulos + objetivos de aprendizaje).
2. Definir arquitectura (hosting, almacenamiento multimedia, DB).
3. Crear contenido (texto, multimedia, ejercicios autoevaluables).
4. Implementar panel docente con reporting básico.
5. Pruebas de usabilidad y accesibilidad.

**Restricciones:**
- Mobile-first y accesibilidad básica.
- Control de versiones y backup en repositorio.

**Rúbrica (50 pts):**
- Cobertura curricular y calidad pedagógica (15 pts).
- Integración técnica y despliegue (15 pts).
- Experiencia de usuario y accesibilidad (10 pts).
- Documentación, testing y reproducibilidad (10 pts).

**Extensión (+6 pts):** integrar analítica con IA para recomendaciones personalizadas.
