# Ejercicio 4 — Generación masiva de documentos y automatización (Plantillas + Mail Merge + Script)

**Objetivo:**
Construir una plantilla profesional y automatizar la generación masiva de documentos personalizados a partir de una hoja de datos.

**Entregables:**
- Plantilla (`plantilla.docx` o `plantilla.odt`).
- Hoja de datos (`datos.xlsx`) con 50 registros de ejemplo.
- Script de automatización (`generar.py` o `mailmerge.gs`).
- Paquete de PDFs generados (`salida_pdfs/`).

**Pasos sugeridos:**
1. Diseñar plantilla con estilos y campos a reemplazar.
2. Preparar la hoja de datos y normalizar valores.
3. Implementar script para generar documentos y convertir a PDF.
4. Validar formatos, encabezados, numeración y tabla de contenidos.
5. Entregar logs y manejo de errores.

**Restricciones:**
- Mantener consistencia del estilo corporativo.
- Incluir índice dinámico y numeración correcta.

**Rúbrica (30 pts):**
- Plantilla y estilo (8 pts).
- Correctitud de datos en los PDFs (8 pts).
- Robustez del script (8 pts).
- Documentación y facilidad de reproducción (6 pts).

**Extensión (+4 pts):** envío automático por correo y registro de envíos en hoja de cálculo.
