# Ejercicio 5 — Inventario con base de datos y CRUD web (Access + HTML/CSS/JS + Hojas)

**Objetivo:**
Modelar una base de datos Access para inventario y desarrollar una interfaz web que permita operaciones CRUD, junto con reportes exportables a hoja de cálculo.

**Entregables:**
- `inventario.accdb` con esquema y datos de prueba.
- Frontend (carpeta `web/`) con CRUD funcional.
- Script de exportación a `XLSX/CSV` y ejemplos de reportes (`reportes/`).
- Instrucciones de despliegue.

**Pasos sugeridos:**
1. Diseñar tablas: `Productos`, `Categorias`, `Movimientos`, `Usuarios`.
2. Implementar integridad referencial y datos de prueba.
3. Crear frontend estático o con servidor mínimo para CRUD.
4. Añadir validaciones y fotos optimizadas de producto.
5. Implementar exportación filtrada y generación de reportes.

**Restricciones:**
- Mantener integridad referencial.
- Fotografías optimizadas y vinculadas desde la UI.

**Rúbrica (35 pts):**
- Diseño relacional y normalización (10 pts).
- Funcionalidad CRUD y usabilidad (10 pts).
- Calidad de los reportes y exportaciones (8 pts).
- Documentación y despliegue (7 pts).

**Extensión (+5 pts):** alertas por bajo stock y notificaciones por correo o registro en hoja.
