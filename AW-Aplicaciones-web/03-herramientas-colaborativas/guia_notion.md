## 🤔 ¿Qué es Notion?

**Notion** es una herramienta "todo en uno" que funciona como:

- **Base de datos** (como Excel, pero más visual)
- **Documentación** (como Word, pero más organizado)
- **Wiki personal** (como Wikipedia, pero tuya)
- **Sitio web** (puedes compartirlo público)
- **Herramienta colaborativa** (trabaja con otros en tiempo real)

### En una frase:
> Notion es un espacio digital donde puedes guardar, organizar, documentar y compartir información de forma visual y colaborativa.

### ¿De dónde viene?
Notion fue creada en 2016 por Ivan Zhao. Hoy es usado por millones de personas: estudiantes, profesores, empresas, equipos remotos.

## 🧩 Conceptos Básicos

### 1. Workspace
Es tu "espacio de trabajo" personal o de equipo. Todo lo que crees vive dentro.

**Analogía:** Es como tu carpeta "Mi PC" en Windows.

### 2. Páginas
Los "documentos" o "secciones" donde escribes.

**Analogía:** Como documentos de Word.

### 3. Bloques
Los "elementos" que puedes insertar: texto, tablas, imágenes, código, etc.

**Analogía:** Bloques LEGO que puedes combinar.

### 4. Bases de Datos
Tablas estructuradas con propiedades (como Excel avanzado).

**Analogía:** Una hoja de cálculo, pero con más poder visual.

### 5. Vistas
Formas diferentes de ver los mismos datos:
- **Tabla** - Como Excel
- **Tablero Kanban** - Tarjetas movibles
- **Calendario** - Eventos en fecha
- **Galería** - Como Pinterest
- **Lista** - Viñetas ordenadas

**Analogía:** Es la misma información, solo cambias cómo la miras.

## 🚀 Tu Primer Proyecto en Notion

### Paso 1: Crear una Cuenta

1. Ve a https://www.notion.so
2. Haz clic en "Sign up"
3. Regístrate con Google, Apple o correo
4. ¡Listo! Ya tienes tu workspace

### Paso 2: Conocer la Interfaz

```
┌─────────────────────────────────────┐
│  NOTION (Barra superior)            │
├──────────┬──────────────────────────┤
│ BARRA    │                          │
│ LATERAL  │   ÁREA PRINCIPAL         │
│ (Páginas)│   (Edición)              │
│          │                          │
└──────────┴──────────────────────────┘
```

**Elementos clave:**
- **Barra lateral:** Acceso a todas tus páginas
- **+ Página:** Crea nuevas páginas
- **Botón +:** Añade bloques dentro de una página
- **Opciones (...):** Menú contextual

### Paso 3: Crear tu Primera Página

1. En la barra lateral, haz clic en **"+ Añadir página"**
2. Dale un nombre (ej: "Mi Primer Proyecto")
3. ¡Empieza a escribir! Puedes:
   - Escribir texto normal
   - Hacer títulos (`# Título`)
   - Crear listas
   - Insertar imágenes

### Paso 4: Insertar Elementos (Bloques)

Presiona `/` y se abrirá un menú. Escribe lo que quieres:

```
/text        → Párrafo de texto
/heading     → Título (H1, H2, H3)
/table       → Tabla
/image       → Insertar imagen
/video       → Insertar vídeo
/code        → Bloque de código
/quote       → Cita
/divider     → Separador
/todo        → Lista de tareas
/toggle      → Contenido deslizable
/callout     → Cuadro de aviso
```

**Ejemplo:**
```
Escribe: /heading
Presiona Enter → Se convierte en título
```

## 💡 Ejemplos Prácticos

### Ejemplo 1: Base de Datos de Contactos (CRM Simple)

**Objetivo:** Guardar información de clientes/contactos

#### Estructura

```
TABLA: Contactos
├── Nombre (Texto)
├── Email (Correo)
├── Teléfono (Teléfono)
├── Empresa (Texto)
├── Estado (Selección: Activo/Inactivo)
├── Fecha Contacto (Fecha)
└── Notas (Texto largo)
```

#### Pasos de Creación

1. Crea una nueva página: "Contactos"
2. Escribe `/table` (insertar tabla)
3. Notionagrega una tabla vacía
4. Clic en "+" para añadir columnas (propiedades)
5. Para cada contacto, rellena la información
6. Crea una **Vista Kanban** agrupada por "Estado"

#### Resultado

Verás todos los contactos organizados en columnas (Activo, Inactivo, etc.). Si cambias el estado de uno, se mueve automáticamente.

---

### Ejemplo 2: Wiki de Documentación (Para un Equipo)

**Objetivo:** Crear un manual o documentación centralizada

#### Estructura

```
PÁGINA PRINCIPAL: Documentación
├── 📄 Introducción
├── 🛠️ Guías
│   ├── Cómo usar la app
│   ├── Solucionar problemas
│   └── Preguntas frecuentes
├── 👥 Equipo
│   ├── Contactos
│   └── Roles
└── 📋 Recursos
    ├── Plantillas
    └── Enlaces útiles
```

#### Pasos de Creación

1. Crea una página principal "Documentación"
2. Añade **sub-páginas** (arrastra hacia la derecha):
   - Introducción
   - Guías
   - Equipo
   - Recursos
3. En cada sub-página, escribe el contenido
4. Usa **toggles** `[toggles/desplegables]` para contenido largo
5. Inserta **enlaces internos** para navegar entre páginas

#### Resultado

Tienes un manual completo, bien organizado, que se ve profesional y es fácil de navegar.

---

### Ejemplo 3: Gestor de Proyectos Simple

**Objetivo:** Rastrear tareas y su progreso

#### Estructura

```
TABLA: Tareas
├── Tarea (Texto)
├── Responsable (Persona)
├── Estado (Selección: To Do / En Progreso / Hecho)
├── Prioridad (Selección: Baja / Media / Alta)
├── Fecha Límite (Fecha)
└── Descripción (Texto largo)
```

#### Vistas Múltiples

1. **Vista Tabla:** Ve todas las tareas en formato Excel
2. **Vista Kanban:** Arrastra tareas por estado (visual y dinámico)
3. **Vista Calendario:** Ve fechas límite de un vistazo
4. **Vista Lista:** Filtradas por responsable o prioridad

#### Resultado

El mismo proyecto visto de 4 maneras. Cada persona elige cómo trabajar mejor.

## 👥 Colaboración y Compartición

### Nivel 1: Compartir un Documento Individual

#### Pasos

1. Abre la página que quieres compartir
2. Haz clic en **"Share"** (arriba derecha)
3. Selecciona el tipo de permiso:
   - **Can edit** - Puede editar
   - **Can comment** - Solo comentarios
   - **Can view** - Solo lectura

4. Copia el enlace y comparte

#### Ejemplo
```
Profesor crea un documento → Genera enlace compartido → 
Alumnos acceden sin crear cuenta → Ven y editan en tiempo real
```

---

### Nivel 2: Compartir el Workspace Completo

#### Para Equipos de Trabajo

1. En la barra lateral, abajo, haz clic en **"Invite"**
2. Añade emails de compañeros
3. Asigna permisos:
   - **Editor** - Acceso completo
   - **Commenter** - Solo comentarios
   - **Viewer** - Solo lectura

#### Ventajas

✅ Todos ven los cambios en tiempo real
✅ Historial de quién cambió qué
✅ Comentarios para comunicarse
✅ Pueden crear sus propias páginas

---

### Nivel 3: Publicar en Web (Public Link)

Esto permite compartir como **sitio web público** (sin necesidad de crear cuenta).

#### Pasos

1. Abre la página
2. Haz clic en **"Share"**
3. Activa **"Share to web"**
4. Copia el enlace público
5. ¡Cualquiera puede verlo sin cuenta!

#### Casos de Uso

- Portafolio profesional
- Blog
- Catálogo de productos
- Documentación pública
- CV interactivo

#### Ejemplo
```
Creas un portafolio en Notion → Lo publicas → 
Compartes enlace en LinkedIn → La gente ve tu trabajo sin Notion
```

---

### Nivel 4: Colaboración en Tiempo Real

Cuando múltiples personas están editando:

1. **Avatares en la esquina superior** - Ves quién está escribiendo
2. **Cursor de otros en color** - Ves dónde están escribiendo
3. **Chat de comentarios** - Comunícate sobre cambios
4. **Historial de versiones** - Recupera versiones antiguas

#### Flujo Típico de Equipo

```
Profesor crea estructura → Asigna tareas a alumnos → 
Alumnos rellenan su sección → Profesor revisa y comenta → 
Publicar versión final
```

## 🎯 Consejos y Mejores Prácticas

### ✅ Organización

1. **Usa la jerarquía** - Sub-páginas crean carpetas
2. **Nómbralo bien** - Usa emojis + nombres claros
   - ✅ "📋 Plan Semana 1"
   - ❌ "Doc 1"
3. **Una base de datos por tema** - No mezcles contactos con tareas
4. **Usa plantillas** - Para tareas repetitivas

### ✅ Diseño

1. **Añade emojis** - Rompen monotonía visual
2. **Usa colores** - Elige paleta consistente
3. **Crea portada** - Primera impresión importante
4. **Espacios en blanco** - No satures la página

### ✅ Colaboración

1. **Comunica claramente** - Usa títulos descriptivos
2. **Comenta cambios importantes** - Para que otros entiendan
3. **Establece permisos** - No todos necesitan editar todo
4. **Haz copias** - Antes de cambios grandes

### ✅ Mantenimiento

1. **Limpia regularmente** - Borra información obsoleta
2. **Actualiza fechas** - Mantén calendarios al día
3. **Revisa acceso** - ¿Quién debería tener acceso?
4. **Haz backups** - Exporta información importante

## 🆘 Troubleshooting (Problemas Comunes)

| Problema | Solución |
|----------|----------|
| "No puedo editar" | Revisa permisos (Share → Can edit) |
| "Desaparecieron mis cambios" | Recarga la página o revisa historial |
| "La tabla es muy lenta" | Divide en múltiples tablas pequeñas |
| "No encuentro algo" | Usa búsqueda (Ctrl/Cmd + K) |
| "Quiero cambiar el icono de página" | Haz clic en el icono en el título |
