# 03 - Herramientas Colaborativas

Este módulo se centra en las herramientas colaborativas que permiten a los equipos trabajar de manera eficiente en entornos digitales, eliminando silos de información y facilitando la comunicación, gestión de proyectos y automatización con IA. Está diseñado para transformar la forma en que los estudiantes gestionan flujos de trabajo, desde la comunicación en tiempo real hasta la integración de sistemas ERP.

## 🎯 Objetivos de Aprendizaje
- Comprender el impacto de las herramientas colaborativas en la eliminación de silos y mejora de la productividad.
- Aprender a seleccionar y configurar herramientas adecuadas para diferentes necesidades empresariales.
- Desarrollar habilidades en comunicación digital, gestión de proyectos y uso de IA para automatización.
- Aplicar conocimientos en escenarios reales mediante ejercicios prácticos y casos de estudio.

## 🛠️ Herramientas Destacadas
- **Comunicación**: Slack, Microsoft Teams, Discord, Zoom.
- **Gestión de Proyectos**: Trello, Asana, Notion, Monday.com.
- **Documentación**: Google Workspace, Microsoft 365, Notion.
- **Diseño**: Figma, Canva, Miro.
- **IA**: ChatGPT, Claude, Midjourney, NotebookLM.
- **ERP**: SAP, Microsoft Dynamics 365, Odoo.

## 📖 Cómo Usar Este Módulo
1. Lee la introducción en `herramientas.md` para familiarizarte con los conceptos básicos.
2. Explora el temario en `guia/temario.md` para entender la estructura del curso.
3. Participa en el desafío de `00-digitaliza-una-pyme.md` para aplicar los conocimientos de manera práctica.
4. Consulta las guías en `guia/` para mejores prácticas en comunicación y proyectos.
5. Revisa los casos en `fichas-clientes.md` y `guia/02-casos-usos-proyectos.md` para inspiración en ejercicios.

Este módulo prepara a los estudiantes para el mundo laboral digital, enfatizando la colaboración y la eficiencia.
